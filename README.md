This project is a responsive, multilingual website built for Raíz Psychotherapy, a psychotherapy practice providing queer and BIPOC-affirming mental health services in California.

The site was developed as a client-facing React application with an emphasis on accessibility, responsive design, clear information architecture, and maintainable component-based code.

Features:
-Responsive interface designed for desktop and mobile devices
-Reusable React components for consistent layout and styling
-Multi-page navigation using client-side routing
-English and Spanish content support
-SEO-focused page structure and metadata
-Architecture designed to accommodate future integrations such as online scheduling and electronic health record (EHR) services
